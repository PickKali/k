# Kali's Site (k)
The repository name is just "k" so that the github url is just a single letter so it's easier for people to get to.

This is where I store most of my stuff!

The main page is essentially a portfolio of projects.
I know this will take a while, but the plan is for each project to have its own modal the explain the details. 
The project size tags are XS/S/M/L/XL, which is the overall scale of the project. 
* XS: afternoon projects
* S: being a few days
* M: about a week
* L: weeks
* XL: months

The objective of these projects are about recitations of what I learned from the process of making them!
